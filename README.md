# 📌 DOM Manipulation Project

![DOM Project Banner](assets/img/banner.png)

This project demonstrates how to use **JavaScript DOM (Document Object Model)** to create, update, delete, and manipulate HTML elements dynamically.  
It is a beginner-friendly project to practice **event handling**, **element selection**, and **real-time updates**.

---

## 🚀 Features
- Add new items dynamically  
- Delete existing items  
- Change styles using JavaScript  
- Handle user input with events  
- Real-time updates in the browser  

---

## 🛠️ Technologies Used
- **HTML5** → Structure of the page  
- **CSS3** → Custom styling  
- **Bootstrap 5** → Responsive design & layout  
- **JavaScript (ES6)** → DOM manipulation logic
